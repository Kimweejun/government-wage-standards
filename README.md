# 정부지원사업 인건비 기준 조회

우리 회사가 수행하는 정부지원 과제마다 인건비를 어떻게 넣을 수 있는지를, 사람의 상태(대표자·기존 직원·신규 채용·가족·학생·외부 전문가)에 따라 **한 페이지**에서 비교합니다. 아래로 이어서 회사 조건으로 신청을 검토할 사업과 전체 인건비 기준 검색이 있습니다. 원문 확인일은 **2026-11-17**(공통 기준), **2026-11-24**(회사·수행 과제)입니다.

> 공개 원문을 정리한 참고 자료입니다. 실제 편성은 각 과제의 협약서·승인 사업계획서와 전담기관 안내가 우선합니다. 회사의 편성 금액과 참여 인력 정보는 싣지 않습니다.

## 페이지 구성 (`index.html`, 한 페이지)

| 영역 | 내용 |
|---|---|
| 우리 회사 | 소재지·업종·설립일(업력)·규모·연구소·벤처 인증, 그리고 이 조건 때문에 달라지는 인건비·지원 기준 |
| 수행 과제 × 인력 상태 | K-방산 스타트업 1단계, 국방벤처 지자체 개발비, 금오공대 RISE, 대구대 창업중심대학을 열로, 인력 상태를 행으로 놓은 비교표. 칸마다 판정(현금 가능·조건부·현물만·불가·확인 필요), 조건, 원문 번호. 과제별 근거·사업비 구조·산식·증빙 |
| 신청 검토 사업 | 회사 조건(구미·업력·연구소·벤처·인원)으로 걸러낸 사업과 모집 상태 |
| 전체 기준 검색 | 국가 R&D 공통 기준과 부처·사업별 기준 24개. 키워드 검색, 기관·인력 유형·학력·상태 필터, 개인 조건 계산 |
| 학력별 비교 · 계산기 · 출처 · 용어 | 같은 페이지 아래쪽 |

`company.html`은 예전 주소를 위한 이동 페이지입니다.

## 데이터 수정과 빌드

| 파일 | 내용 |
|---|---|
| `company_profile.py` | 회사 조건, 인력 상태, 수행 과제별 판정, 신청 검토 사업 |
| `wage_rules.py` | 전체 기준, 출처(S01~), 용어, 확인 필요·변경 이력 |
| `page.html` | 화면 템플릿 |

```powershell
python wage_rules.py --check   # 출처 연결, 표 수치, 회사 영역 출처까지 일관성 검사
python build_html.py           # 검사 통과 시 index.html과 sources.json 생성
```

## Python 조회

```powershell
python wage_rules.py 학생인건비 --brief
python wage_rules.py --program new-research-hire --grade master --salary 3800000
```

## 상태 표시

- **현행**: 원문과 대조해 확인한 기준
- **확인 필요**: 공개 원문에 규정이 없거나 원문끼리 다른 기준. 항목의 "주의"와 "확인 필요·개정 예정"에 이유와 문의처를 적었습니다.
